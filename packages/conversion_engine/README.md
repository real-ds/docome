# Conversion Engine

Owns document conversion and high-fidelity reconstruction.

Initial targets:

- PDF → DOCX
- DOCX → PDF
- PDF → XLSX
- XLSX → PDF
- PDF → PPTX
- PPTX → PDF
- PDF → images
- images → PDF
- HTML → PDF
- PDF → Markdown
- PDF → TXT

High-fidelity PDF → DOCX is a flagship capability and requires visual
regression benchmarks.
