Capabilities

What it does

Built on modular engines. Each operation is deterministic, scriptable, and runs locally.

▦

PDF Operations

Merge, split, extract, remove, rotate, compress. Page-level control over any PDF document.

⇄

Conversion

PDF to DOCX, XLSX, PPTX, Markdown, plain text. And back. Preserves layout and structure.

✎

E-Signatures

Create typed signatures, place them on documents, add form fields. Full signing workflows.

◉

OCR

Turn scanned documents into searchable, selectable text. Tesseract and EasyOCR backends.

▢

Image Engine

Convert images to PDF, render PDF pages as images. Batch processing built in.

◆

Security

Password protection, AES-256 encryption, metadata editing. Your files never leave your disk.

Scriptable by default

Every operation available through the CLI. Pipe it, script it, automate it.

$ docome pdf merge report.pdf appendix.pdf -o final.pdf
Merging 2 files...
Merged PDF saved to: final.pdf
$ docome convert pdf2docx final.pdf -o final.docx
Converting final.pdf to DOCX...
DOCX saved to: final.docx
$
